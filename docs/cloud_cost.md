# Cloud-cost model

Geometry-aware routing is a cost question, not just a fidelity question:
on time-billed quantum cloud, deeper circuits bill more. This page turns
the measured two-qubit depths into relative QPU cost. Generated by
`scripts/cloud_cost.py`; numbers come from `results/tables/summary.csv`
and `results/tables/scaling.csv`.

## Pricing (checked 2026-10-03)

- **IBM Quantum Pay-As-You-Go:** $96/minute = **$1.60 per QPU second**,
  billed per second, 1-second minimum. Billing counts QPU execution time
  only (queue time excluded). Source: IBM Quantum products page via
  quantumcomputingcost.com (verified 2026-09-07).
- **AWS Braket:** $0.30 per task + per-shot device pricing (e.g. Rigetti
  Cepheus $0.000425/shot, IonQ Forte $0.08/shot). Source:
  aws.amazon.com/braket/pricing.

## Model and assumptions

1. On time-billed QPUs, execution time per shot scales with two-qubit
   depth (the dominant cost for these circuits).
2. Relative cost per shot = depth_A / depth_B, same device and shot
   count. **This ratio needs no assumed gate time** and is the headline
   result.
3. Protected runs discard shots, and discarded shots still bill, so cost
   per *useful* shot is multiplied by 1 / yield.
4. Dollar figures additionally assume ~0.5 us per two-qubit layer
   (typical superconducting gate time). They are illustrative; the 1.9x
   ratio does not depend on this assumption.
5. On per-shot billing (Braket), depth does not change the bill. This
   model applies to time billing only.

## Results

Size-matched at 127 qubits (noisy condition): heavy-hex-127 needs 17
two-qubit depth vs hyperbolic-127's 9, so the Eagle-style layout costs
**~1.9x the QPU time per shot**. Illustrative IBM billing for 1M shots:
$13.60 vs $7.20 (about 47% cheaper).

Protected cost per useful shot (depth / yield), matrix rows (note: these
rows have different qubit counts, 5 / 127 / 20):

| Topology | 2q depth | Yield | Cost units |
|---|---|---|---|
| t-shape | 7 | 0.913 | 7.66 |
| heavy-hex-127 | 26 | 0.795 | 32.71 |
| hyperbolic-20 | 9 | 0.891 | 10.10 |

Reading: on the longest route, protection buys fidelity (+0.113) but the
bill per useful shot is ~3.2x the hyperbolic-20 route's, because the
deeper circuit bills longer *and* one in five shots is discarded.

## Limitations

- This is a model over simulated depths, not a measured cloud bill.
- Real device gate times, parallelism, and pricing tiers vary; relative
  ordering is more robust than absolute dollars.
- Prices change; re-check before citing.
